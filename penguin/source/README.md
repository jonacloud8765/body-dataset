# Source material

Upload the three source files for the penguin music video into this folder:

1. **Penguin reference sheet**: PNG, JPG, or PDF. This is the character source of truth.
2. **Full song**: WAV preferred, MP3 is fine. All timing comes from this file.
3. **Vocals**: the isolated vocal stem or vocal take (WAV or MP3).

Any file names work. GitHub's web uploader takes files up to 25 MB each. If the WAV is
larger, upload an MP3 of it or push with git (git allows files up to 100 MB).
