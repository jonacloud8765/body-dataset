# Source material

The three source files live here locally and are **not committed**: this repository is public,
and they are an unreleased song, its vocal stem, and original artwork. `.gitignore` keeps them out.

| File | What it is |
|---|---|
| `im-the-penguin.mp3` | The full song. The master clock for the video. |
| `im-the-penguin-vocals.mp3` | The isolated vocal. Used for line timing and lip sync, never mixed in. |
| `him-model-sheet.jpg` | The HIM model sheet. The source of truth for the character. |

To rebuild the analysis or render the video in a new checkout, put the three files back here
under these names. If the vector file behind the model sheet exists, add it here too.
